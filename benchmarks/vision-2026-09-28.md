# Local appearance extraction benchmark

Recorded on the same Apple M3 Pro / arm64 host as the reconciliation benchmark,
using the SwiftPM release configuration. The same test ran before and after
replacing per-cell temporary RGB arrays with fixed output slots in BoardVision.
No raster size, feature layout, background removal, thresholds or distance
arithmetic were changed by this optimization.

```sh
CHESSLENS_BENCHMARK=1 swift test -c release --disable-sandbox \
  --filter VisionPerformanceTests
```

Input: `fast-pawn-reply.png`, cropped to `(51, 107, 1171, 1172)`.
40 observations: 5 warm-up calls and 35 timed calls. Each call extracts all 64
square appearances, including CoreGraphics rasterization. Both runs produced
the same aggregate test checksum, 15532.38.

| Appearance extraction | Before | After |
| --- | ---: | ---: |
| Median | 13.0059 ms | 8.5811 ms |
| p95 | 14.0193 ms | 9.7651 ms |

Approximately **1.52× faster** on this workload (34% less median time).
This excludes screen capture, recognition, reconciliation, the two-second
stability wait and Stockfish. It is not an end-to-end latency claim.
